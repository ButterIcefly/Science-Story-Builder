# 科普 8 段式内容生成器 · Science Story Builder

> 输入任意主题，自动生成「先现象、再探索、后解释」的 8 段式儿童科普互动内容骨架。
> 为 9–12 岁孩子设计，支持 AI 生成、逐段编辑、标注筛选与导出。

![科普 8 段式内容生成器](github-social-preview.png)

一个**纯本地、单文件 HTML** 的儿童科普内容设计工具。打开即用，无需安装、无需服务器、不上传任何数据。

---

## ✨ 功能总览

### 🧠 AI 生成
- 点击 **AI 生成 8 个部分**，接入大模型接口，按 8 段式结构为任意主题生成内容
- 支持OpenAl/Claude/DeepSeek / 硅基流动 / 通义千问等，选择后 Base URL 自动填充，也可自定义地址与模型名
- 支持 **结构化输出**（JSON Schema / json_object），返回内容自动校验、字段归一化、缺段补齐
- **自定义 Prompt**：可覆盖默认提示词，打开面板即可查看/编辑/恢复默认
- **测试连接**：一键验证接口连通性，清晰提示密钥、权限、模型、网络等问题

### 📝 8 段式内容结构
每一段包含四个可编辑区块：
- **本段目标**
- **文案内容**
- **交互 / 画面设计**
- **设计检查**
- **你的标记 / 修改意见**

内置 AI 提示词遵循科普设计规范：先现象、后知识；让孩子操作"原因"；反馈先描述不解释；允许猜错；单变量实验；科学透视可视化；术语放最后；必须迁移；最后自己讲出来。

### ✍️ 逐段标注与整理
- 每段可 **评星**（★★★ 重要程度）
- 每段可标记状态：**已确认 / 需修改 / 待删除**
- 按星级或状态**筛选**卡片
- 每段可 **编辑**、**复制本段**、写**修改备注**（自动保存到 localStorage）
- 一键 **复制全部**、**导出 Markdown**

### 🎨 自定义面板
- **页面背景**：上传图片 + 模糊调节（0–36px）
- **顶图背景**：上传后自动打开**裁剪页**——裁剪框与顶图同比例，支持**拖动 + 滚轮缩放**，裁出效果即铺满顶图区
- **卡皮巴拉开关**：一键隐藏/显示卡皮巴拉（含进度条、冷笑话气泡），默认显示
- **卡皮巴拉说话内容**：自定义冷笑话（每行一句），**每行最多 10 字、可多行**；可调节说话间隔（3–15 秒）
- 所有设置存 localStorage，重载后保留

### 🐹 卡皮巴拉伙伴
- 由 7 帧透明 PNG 组成的**咀嚼动画**，加载即就绪
- **点击**：受击反馈 + 随机小字（好运 +1 / 美貌 +1 / 灵感 +1 …）三向飘出
- **待机冷笑话**：鼠标6 秒没动，卡皮巴拉讲冷笑话（内置 22 条 + 可自定义）
- **AI 生成时进度条**：进度条贴合卡皮巴拉头顶，随生成进度实时增长，完成后停在满格

### 🎨 外观与主题
- 三种皮肤：**朴素版 / 碰撞版 / 内敛版**，右上角一键切换
- 页面背景与顶图支持上传本地图片，支持模糊程度自定义

## 🚀 使用方法

1. **打开**：直接用浏览器打开 `8段式内容生成器-最终版.html`（或用任意静态服务器托管）
2. **默认内容**：页面打开即展示「为什么会有影子」的完整 8 段内容
3. **AI 生成**（可选）：
   - 点击工具栏 **AI 生成设置**
   - 选择服务商（地址自动填充）→ 填写 API 密钥 → 填写模型名
   - 可编辑自定义 Prompt、点 **测试连接** 验证
   - 保存后回到顶部输入任意主题 → 点 **AI 生成 8 个部分**
4. **整理**：对每段评星、标记状态、写备注、筛选
5. **导出**：复制全部 或 导出 Markdown 文档

> 未配置 API 密钥时，默认主题仍可展示内置内容；其他主题会生成通用结构并提示配置 AI。

## 🔌 接口配置

| 服务商 | Base URL（自动填充） | 协议 |
|---|---|---|
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn/v1` | OpenAI 兼容 |
| DeepSeek | `https://api.deepseek.com/v1` | OpenAI 兼容 |
| OpenAI | `https://api.openai.com/v1` | OpenAI 兼容 |
| Anthropic Claude | `https://api.anthropic.com` | Anthropic 原生 |
| 阿里云百炼 Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | OpenAI 兼容 |
| 自定义 | 自定义地址 | OpenAI 兼容 |

- API 密钥仅保存在**本机浏览器 localStorage**，不上传任何服务器
- Anthropic 原生接口使用浏览器直连（`anthropic-dangerous-direct-browser-access`），符合官方浏览器调用规范
- OpenAI 兼容接口自动处理 `response_format` 兼容性，不支持时自动降级重试

## 🛠 技术细节

- **纯前端单文件**：HTML + CSS + 原生 JavaScript，无任何外部依赖（无框架、无构建）
- 数据全部存储在浏览器 `localStorage`（主题内容、背景设置、AI 配置、皮肤偏好）
- AI 生成使用 `fetch` + 结构化输出，`AbortController` 支持取消
- 拖拽 / 裁剪 / 动画均使用浏览器原生 API（Pointer Events / Canvas / CSS Animation）
- 所有用户数据不经过任何第三方服务器
